# 🎃 Patisson Game 2.0

Полная переработка [Patisson Game](https://github.com/fedor655/Patisson-Game) —
та же ферма с патиссонами, но на собственном движке поверх
[**Panda3D**](https://www.panda3d.org/) с физически корректным освещением,
процедурным миром и живыми жителями.

> Ветка `patisson-2.0`. Оригинальная игра Богдана на Ursina — в ветке
> [`main`](https://github.com/fedor655/Patisson-Game/tree/main).

## 🚀 Запуск

```bash
pip install -r requirements.txt
python -m patisson2
```

Всё. **Ресурсы не нужно нигде скачивать** — все 3D-модели лежат в репозитории
(`assets/models`, ~6 МБ), а земля, трава, вода, небо, облака и весь звук
генерируются кодом. Это главное отличие от 1.0, где игре требовался
установщик на 650 МБ.

При первом запуске игра около секунды генерирует звуковые эффекты в
`~/.patisson2/audio/`, а музыку дорисовывает в фоне.

Пресеты качества:

```bash
python -m patisson2 --low
python -m patisson2 --ultra
python -m patisson2 --fullscreen
```

Пересобрать модели после правок в генераторе:

```bash
python -m patisson2.tools.make_assets
```

Снять скриншоты (игра рендерится offscreen, окно не нужно):

```bash
python -m patisson2.tools.shots
```

### Требования

Python 3.10+, видеокарта с OpenGL 4.3. Разрабатывалось и проверялось на
GeForce RTX 3070 Laptop (OpenGL 4.6): **90–110 fps в 1600×900** на пресете по
умолчанию, со звуком и погодой. Разброс — это троттлинг ноутбука, а не разница
в сцене: дождь и снег стоят меньше миллисекунды. Если тормозит — `--low`
(без SSAO и лучей солнца, тени 1024, травы меньше).

## 🌱 Что нового по сравнению с 1.0

### Движок и графика

Всё написано с нуля на Panda3D + GLSL 4.60, без готовых пайплайнов:

- **PBR-освещение** (Cook-Torrance GGX) с корректным ambient-членом (split-sum).
- **Атмосфера с однократным рассеянием** (Рэлей + Ми) считается каждый кадр в
  маленькую равнопромежуточную таблицу неба. Из неё берётся и рассеянный свет,
  и воздушная перспектива — поэтому освещение сцены физически согласовано с тем
  небом, которое видно в кадре, в любое время суток.
- **Тени солнца**: карта 2048² на радиус 48 м (4,7 см на тексель), PCF,
  смещение вдоль нормали, кадр следует за игроком и привязан к сетке
  текселей — тени не «плывут» при ходьбе.
- **Постобработка**: SSAO, bloom, объёмные лучи солнца, тонемаппинг ACES,
  цветокоррекция, виньетка, зерно, FXAA.
- **Процедурный ландшафт**: сетка сгущается к центру, поэтому у фермы
  треугольники метрового масштаба, а по краю мира поднимаются холмы — границы
  карты не видно.
- **Трава на GPU**: одна травинка, ~170 000 инстансов (на `--ultra` — 520 000), позиция, наклон, размер и
  цвет каждой считаются в вершинном шейдере из номера инстанса. Трава знает
  высоту земли, уклон, воду и вскопанные грядки.
- **Вода**: волны Герстнера, **зеркальное отражение мира** (сцена рисуется
  второй раз камерой, отражённой сквозь плоскость воды, и шейдер берёт результат
  по собственной экранной координате фрагмента), поглощение по реальной глубине
  (читается высота дна), каустики, пена у берега. Проход включается только когда
  игрок рядом с прудом и стоит 0,3 мс.
- **Сутки и времена года**: положение солнца считается по часовому углу и
  склонению, зимой день короче. Небо, цвет света, экспозиция, цвет травы и
  деревьев следуют за сезоном.

### 🔊 Звук: тоже сгенерирован кодом

Записанных звуков в игре нет ни одного. В репозитории лежит **синтезатор**
(`patisson2/audio/`) — осцилляторы, огибающие, фильтры, ревербератор — и
описания всех звуков как функций. При первом запуске игра рендерит из них
27 файлов в кэш `~/.patisson2/audio/`:

- **19 эффектов**: удар мотыги, полив, посадка, срыв плода, заброс удочки,
  всплеск, монеты, скрип колодца, куры, корова, гром, шаги (четыре варианта с
  разбросом высоты тона), клики интерфейса, фанфара достижения.
- **4 фоновых слоя**: птицы днём, сверчки ночью, ветер, дождь — все
  бесшовно зациклены и плавно перетекают друг в друга по времени суток и погоде.
- **4 музыкальные темы** (утро, день, вечер, ночь) по 65 секунд — аккордовая
  прогрессия, арпеджио, бас и мелодия из пентатоники, с ревербератором.
  Музыка сменяется по часам с плавным кроссфейдом.

Эффекты и фон генерируются за секунду, музыка — в фоновом потоке, поэтому
запуск не ждёт её. Так весь звук стоит репозиторию несколько килобайт кода
вместо 14 МБ WAV-файлов.

### 🔦 Фоторежим: настоящая трассировка лучей

Клавиша **`P`**. Игра снимает геометрию сцены прямо из графа, строит по ней BVH,
загружает всё в видеопамять и запускает **compute-шейдер, который трассирует
пути** — с мягкими тенями от солнечного диска, глобальным освещением на
несколько отражений и русской рулеткой. Картинка накапливается прогрессивно,
пока не станет чистой (обычно несколько секунд).

Это не постэффект «под RTX», а честный path tracer: то, что растеризатор
приближает (SSAO, тени из карты, ambient), здесь считается по-настоящему.
Нужен OpenGL 4.3+ с compute-шейдерами; на RTX 3070 сцена из ~260 000
треугольников доходит до чистой картинки примерно за 5 секунд.

### Мир

- 51 модель, **все сгенерированы кодом** (`patisson2/tools/make_assets.py`):
  дом, амбар, колодец, прилавок, забор, пугало, ящики, бочки, фонари, деревья
  четырёх видов, кусты, камни, камыш, кувшинки, цветы, куры, корова, кот,
  бабочки, рыба, патиссон на четырёх стадиях роста и жители,
  разобранные на части для анимации.
- **Живность**: куры бродят у амбара, коровы пасутся, кот гуляет у дома,
  бабочки летают над грядками.
- **Три жителя** с распорядком дня: Богдан работает на грядках, потом стоит за
  прилавком и уходит домой спать; Марина торгует и ходит рыбачить; Пётр кормит
  кур и пасёт коров. С каждым можно поговорить.
- **У жителей есть лица и походка.** Каждый собран в игре из отдельных частей —
  таз, голова, две руки, две ноги, — и поза считается процедурно: ноги и руки
  ходят в противофазе, таз приподнимается на каждый шаг и кренится в него, а
  фаза шага берётся из пройденного расстояния, а не из времени, поэтому ступни
  не скользят. Голова поворачивается к игроку, когда он рядом, а иначе изредка
  оглядывается по сторонам. На месте — дыхание, за работой — наклон вперёд.
- **Погода видна**: дождь и снег — десятки тысяч частиц, размещаемых целиком в
  вершинном шейдере внутри объёма, который едет за камерой и заворачивается по
  мировой сетке, так что при ходьбе ничего не «выпрыгивает». Капли вытянуты
  вдоль падения и наклонены ветром, снежинки покачиваются; и те и другие
  освещаются небом вдоль собственного луча взгляда, поэтому темнеют к вечеру
  сами. В дождь грядки поливаются сами.
- **Кроны деревьев** собраны из десятка неровных лиственных масс вокруг концов
  веток, а не из одного шара на палке: силуэт рваный, ветки просматриваются,
  низ кроны затенён запечённо в вершинных цветах. У ёлок ярусы с лопастями.
- **Сезоны видно по листве**: цвет деревьев и кустов меняется от свежей
  весенней зелени к золотой осени и выстывшей зиме.

### Интерфейс

- **Главное меню** с медленным облётом фермы на фоне: новая игра, продолжить
  (если есть сохранение), настройки звука, список достижений, выход.
- **Меню паузы** с кнопками — продолжить, сохранить, вернуться в главное меню,
  выйти.

### Игровой процесс

- **Пять культур** — патиссон, морковь, томат, пшеница, тыква. У каждой свои
  сезоны, скорость роста, жажда и цена.
- **Грядки живут**: вода и питание убывают, без них растение вянет и погибает.
  Ухоженное растение даёт больше урожая.
- Копать грядки можно **где угодно** на ровной земле, а не только в одной точке.
- Колодец и пруд — источники воды; лейка имеет ёмкость, золотая лейка втрое
  больше.
- **Рыбалка на восемь видов рыбы.** Что клюнет, зависит от часа и сезона:
  форель берёт на рассвете, щука выходит в сумерках, сом — ночной, а плотва
  клюёт всегда. Изредка попадается золотая рыбка, регулярно — старый сапог.
  Размер случаен со смещением к мелочи, цена считается за килограмм, так что
  крупный экземпляр — событие. Пойманное записывается в журнал.
- **Вываживание требует рук.** Сначала короткое окно на подсечку, потом метка
  ходит по шкале, и её нужно несколько раз остановить в зелёной зоне. У редкой
  рыбы зона уже, метка быстрее и тянуть нужно дольше; три промаха — сорвалась.
  Зачарованная удочка замедляет метку, расширяет окно подсечки и поднимает шанс
  на редкую добычу.
- **Лавка** с семенами, удобрением и тремя улучшениями.
- **Живность**: кур и коров можно кормить пшеницей — сытые несут яйца и дают
  молоко. Над готовым животным висит значок; забрать — `E`.
- **Готовка** у котла (`K`): пять рецептов — хлеб, омлет, уха, патиссоновая
  икра, тыквенный пирог. Блюда стоят в разы дороже сырья (тыква — 88 монет,
  пирог из неё — 320) и восстанавливают силы, если их съесть.
- **Задания и достижения** в журнале — девять заданий и одиннадцать достижений.
- **Сохранение** в `~/.patisson2/save.json`.

## 🗂 Структура

```
patisson2/
  app.py              игровой цикл, ввод, взаимодействия
  config.py           пресеты качества и настройки мира
  engine/
    pipeline.py       рендер-пайплайн: свет, тени, буферы, постобработка
    shaderlib.py      загрузка GLSL с #include и #define
    shaders/          все шейдеры (небо, сцена, ландшафт, трава, вода, пост)
  world/
    terrain.py        генератор высот и меша земли
    water.py          поверхность пруда
    grass.py          меш травинки + инстансинг
    world.py          сборка мира, маска вскопанной земли
    props.py          расстановка моделей, животные
    daynight.py       часы, солнце, времена года
  game/
    player.py         движение и взаимодействие
    farming.py        культуры, грядки, рост
    state.py          инвентарь, деньги, задания, достижения, сохранения
    npc.py            жители и их распорядок
  audio/
    synth.py          осцилляторы, огибающие, фильтры, реверб
    bank.py           определения всех звуков, фонов и музыки
    manager.py        кэш, воспроизведение, кроссфейды, шаги
  ui/hud.py           интерфейс
  tools/
    meshkit.py        процедурное моделирование + запись .glb
    make_assets.py    определения всех моделей
    shots.py          съёмка скриншотов
assets/models/        38 сгенерированных .glb
```
